LEARN / CLEARML BASICS

从一次训练，理解实验管理。

先理解数据如何流动，再学习 SDK 和远程执行。

01 / ORGANIZE

Project → Task

Project 用于组织任务；Task 表示一次代码执行。比较模型时，应同时记录数据版本、划分方式、代码版本和随机种子，避免仅凭一个指标下结论。

02 / OBSERVE

Configuration → Scalars

Configuration 保存学习率、batch size 等配置。Scalars 是随迭代变化的指标。这里画的是同单位的训练 MAE 和验证 MAE；训练误差持续下降而验证误差上升时，应进一步检查过拟合。

03 / TRACE

Console → Artifacts

Console 用来诊断运行问题。Artifacts 是输出文件与相关元数据，可包括评测报告和模型文件。保存了模型制品，不等于已经部署模型；本示例不提供模型发布。

04 / REPRODUCE

Clone → Queue → Agent

克隆任务得到可编辑的 Draft，修改参数后入队成为 Pending，Agent 拉取后开始执行。克隆保留配置，但不会继承原任务的输出结果。这里的 Running 是固定快照，不会自动更新。
