## 齐鲁相关 *2

```
V1.2 要求 DB-5、DB-624、Wax、载气、检测器、峰参数与模拟图；现有 GC 模型基线仅覆盖固定相和 RT 分位数

这段要求的意思是：齐鲁希望 GC 不只是“输入分子，预测一个保留时间”，而是能按真实仪器方法，预测并展示一张接近实际 GC 色谱图的结果。

- **DB-5、DB-624、Wax**：三种常见的 GC 毛细管色谱柱固定相系列。它们的极性和选择性不同，同一个化合物在不同柱子上的保留时间、分离效果可能明显不同。  
  - DB-5：低极性，较通用；
  - DB-624：常用于挥发性有机物等分析；
  - Wax：极性较强，对极性化合物的分离特征不同。  
  这里的核心不是品牌名，而是要求模型能识别并支持多种“色谱柱类型/固定相”。

- **载气**：把样品带着流过色谱柱的气体，例如氮气、氦气、氢气。不同载气、流速或压力会影响分析速度、峰形和保留时间。

- **检测器**：色谱柱分离后的化合物，需要由检测器看到，例如 FID、TCD、MS。它会影响信号响应、可检出的物质范围，以及模拟图中峰高/响应的含义。

- **峰参数**：一张 GC 图中的每个峰不只有“出峰时间”。通常还包括：
  - 保留时间：峰出现的位置；
  - 峰高、峰面积：信号强度或相对含量；
  - 峰宽：峰有多宽；
  - 峰形：是否对称、拖尾或前伸；
  - 峰之间的分离度：两个峰是否真正分开。

- **模拟图**：把上述预测结果绘成横轴为时间、纵轴为检测响应的“色谱图”。多个化合物会显示为多个峰；若峰距离太近或过宽，就会重叠，提示难以分离。

举个直观例子：用户提交 5 个挥发性化合物，选择 DB-624 色谱柱、氮气、某个升温程序和 FID。系统不仅应返回“各化合物约在第几分钟出来”，还希望展示 5 个模拟峰，说明哪些峰可能重叠、各峰大致强弱和宽度。

这比当前常见的 GC 保留时间预测要求高很多。保留时间模型主要解决“峰在哪里”；而多色谱柱、载气和检测器支持，需要更丰富、覆盖这些条件的数据；峰宽、面积、峰形和模拟图还需要额外的物理/经验模型，或者带有完整峰信息的训练数据。

因此，V1.2 的 GC 需求实质上包含三个层级：

1. 多条件保留时间预测：柱型、载气、温度程序等；
2. 多组分分离评估：多个物质是否重叠；
3. 色谱峰模拟与可视化：生成可解释的模拟色谱图。

其中第 1 层相对容易定义，第 2、3 层对数据和模型要求明显更高，不能仅靠现有单一色谱柱条件下的保留时间模型直接承诺。




现有 4 篇论文没有直接解决“色谱模拟峰图 + Rs 标识”的完整问题。

| 论文/现有能力 | 与峰图、Rs 的关系 |
|---|---|
| 手性 HPLC | 预测对映体保留时间、分离相关指标/概率；不是预测峰宽、峰高和完整色谱图 |
| GC | 预测保留时间及区间；不是多柱型、多载气条件下的峰形模拟 |
| TLC | 预测 Rf；没有时间轴峰图和 Rs |
| CC | 预测分离效果、保留体积/时间等；不是在线检测器输出的色谱峰模拟 |

其中最接近的是手性 HPLC 的“是否分离/分离概率”，但它不能直接等价为 Rs。**Rs（分离度）**衡量两个峰分得是否足够开，常见计算不仅需要两个保留时间，还需要峰宽：

\[
R_s = \frac{2(t_{R2}-t_{R1})}{w_1+w_2}
\]

所以只预测“峰在第几分钟出现”还不够；没有峰宽，就不能可靠计算 Rs，更无法画出可信的峰图。

需要的数据主要分两层：

1. 方法与组分数据  
   每次实验应有化合物结构、色谱类型、色谱柱/固定相、尺寸、流动相或载气、流速、温度或梯度程序、进样量、检测器等。

2. 峰与原始信号数据  
   最理想是仪器导出的原始 chromatogram：时间—响应强度序列。  
   至少也要有每个峰的保留时间、峰宽、峰高/面积、峰形指标（如拖尾因子）、峰归属，以及相邻峰的实测 Rs。

难点不在前端画图或 PNG 导出：

- **画模拟峰、标注 Rs、导出 PNG：好做。** 前端拿到“峰位置、宽度、强度、Rs”即可完成。
- **用已有保留时间结果计算 Rs：有限可做。** 前提是用户或系统能提供合理的峰宽；但这属于近似展示，不能称为可靠实验预测。
- **预测真实峰宽、峰高、拖尾和完整峰图：难度较高。** 这些受仪器死体积、柱效、进样量、进样溶剂、检测器、基线、温控和具体方法影响很大，需要成体系、带原始信号或峰积分结果的数据。
- **多化合物真实分离模拟：更难。** 除单峰参数外，还要处理共洗脱、峰重叠、响应差异和检测器差异。

我建议将需求拆成三档，避免一开始承诺过头：

1. **展示型模拟图**：基于预测保留时间，采用固定或用户设置的峰宽和相对强度画示意峰，计算“估算 Rs”，明确标注为模拟/估计。可较快交付。
2. **经验型 Rs 预测**：收集特定柱型、仪器、检测器和方法下的历史峰宽/Rs 数据，预测保留时间与峰宽，再计算 Rs。适合先聚焦一个明确场景。
3. **高可信峰图模拟**：训练峰参数或时间序列模型，使用原始色谱图与完整实验条件。数据、标注、质控和模型工作量最大。

对齐鲁而言，比较稳妥的第一期承诺是“基于模型结果的**示意峰图、估算 Rs 标识和 PNG 导出**”，并在结果中清楚写明不替代实际色谱图和实验验证。若合同要求“真实峰形/定量峰面积预测”，则必须先明确由谁提供带原始图谱或峰参数的数据。
```

````
有，而且**与你们“预测后直接画出模拟色谱图”最接近的研究已经出现了**。我检索到 2025–2026 年的工作后，建议你们不要只把问题定义成“保留时间预测”，而是定义成：

这个定义比单纯做 RT prediction 更接近你们的实际项目，也还有比较明显的研究空间。

### 目前研究大致分成 3 层

第一层、也是最成熟的是 **保留时间 RT 预测**。现在已经有大量 QSRR、XGBoost、Transformer、GNN、迁移学习模型。例如 2025 年的 RT-Pred 可以针对用户自己的 LC 条件训练定制 RT 模型；2026 年的 MC-Retention 已经把**柱类型、buffer/pH 条件**显式输入 GNN，实现跨多个色谱条件的 RT 预测。最新的 FastRet 则使用分子描述符 + LASSO/BRT 做较轻量的 LC retention prediction。([科学直通车][1])

## 你们真正需要预测的，其实不只是两个数

假设某个化合物 \(i\)：

$$
t_{R,i}= \text{predicted retention time}
$$

$$
w_i = \text{predicted peak width}
$$

如果先采用最简单的 Gaussian peak：

$$
y_i(t)
=
A_i
\exp
\left(
-\frac{(t-t_{R,i})^2}{2\sigma_i^2}
\right)
$$

其中：

$$
\sigma_i
=
\frac{FWHM_i}{2\sqrt{2\ln 2}}
\approx
\frac{FWHM_i}{2.355}
$$

那么整个模拟色谱图就是：

$$
Y(t)=\sum_{i=1}^{N}y_i(t)+noise(t)+baseline(t)
$$

也就是说，只要你们已经有：

**RT + peak width + intensity**

其实第一版模拟色谱图就已经可以生成了。

但真实色谱峰通常并不是完美 Gaussian。因此下一步可以进一步预测：

$$
(t_R,\;w,\;A,\;skewness,\;tailing)
$$

然后改成 **EMG（Exponentially Modified Gaussian）**、skew-normal 或其他 peak-shape distribution。

早在 2007 年就已经有研究根据 retention time 和流动相组成进一步预测 peak width / peak shape；当时用 modified Gaussian model，报告的整体 peak-shape prediction error 低于约 5%。([科学直通车][4])

所以这一问题其实有一条很清楚的发展线：

**RT prediction → width prediction → shape prediction → whole chromatogram simulation。**

# 目前研究成熟度可以这样理解

| 目标                       | 当前成熟度  | 典型方法                               | 对你们的重要性    |
| ------------------------ | ------ | ---------------------------------- | ---------- |
| Retention Time           | ★★★★★  | QSRR / XGBoost / GNN / Transformer | 必须         |
| Peak Width               | ★★★    | 物理模型 / GB / SVR / ML               | **非常重要**   |
| Peak Height / Area       | ★★～★★★ | calibration / response model       | 画真实图需要     |
| Peak asymmetry / tailing | ★★     | EMG / distribution fitting         | 第二阶段       |
| Baseline / noise         | ★★★    | empirical / stochastic model       | 模拟真实仪器     |
| 整张 chromatogram          | ★★★    | 以上模型组合                             | **你们最终目标** |

现在文献明显存在一个现象：

> **Retention time prediction 非常拥挤，而 peak width / shape prediction 明显没有 RT 那么成熟。**

2026 年的最新综述也专门提到，目前 predictive chromatography 已经开始同时预测 retention behaviour、peak shape 和 resolution，从而直接做 **in-silico chromatographic simulation**；其中就把 Samuelsson 的 RT+width 工作作为代表案例。([数字对象标识符][5])

这其实对你们是好消息，因为如果单独再做一个：

> SMILES → RT

创新性已经不算很强。

但是如果做到：

> **SMILES + chromatography conditions → RT + peak width + peak shape → simulated chromatogram**

研究价值会明显高很多。

# 你们甚至可以把峰宽和 RT 做成 multi-task learning

比如：

$$
\hat y
=
[
\hat t_R,
\hat w,
\hat\tau
]
$$

Loss：

$$
L
=
\lambda_1 L_{RT}
+
\lambda_2 L_{width}
+
\lambda_3 L_{shape}
$$

如果实验数据允许，还可以加入：

$$
L_{chrom}
=
\|\hat C(t)-C(t)\|_2
$$

最后变成：

$$
L =
L_{RT}
+
\lambda_wL_{width}
+
\lambda_sL_{shape}
+
\lambda_cL_{chrom}
$$

这个就很有意思：

模型不只是要求：

> “RT 算得对。”

还要求：

> “最后生成出来的整张色谱曲线也要和真实 chromatogram 接近。”

这可能比单独训练三个 regression model 更有研究价值。
````
