## 1. 目标与任务切换

本轮目标是：**在本机浏览器中，正常完成五类色谱预测，并通过助手完成预测、已有数据摘要、模型登记草稿与查询。** 验收以真实前后端操作和结果为准。

原负责人模型与汇报描述是历史安排，不作为当前模型或任务分配依据。前端、后端、QA 负责人可直接协调普通接口、缺陷与复验；重大范围/契约决策及用户审批再升级总控。

切换时执行以下规则：

- 让正在执行的子智能体完成当前有界任务，随后留下 checkpoint，不再启动延期功能的新任务。
- candidate-08 若已有在途构建，允许本轮构建结束；失败如实记录，不为完成全平台验收继续扩大整改。
- 每位负责人在自己目录记录：完成项、未验项、相关文件、接口/迁移版本、测试证据、环境依赖、阻塞项、恢复方式及下一步。使用产品自动 config_hash、制品完整性和不可变契约；取消人工位置/文件哈希核对作为验收门槛。
- 当前工作区存在 `.git`；checkpoint 按实际 Git 与工作区状态保存。不得把人工 SHA-256 文件清点设为完成条件；需要的完整性证据由产品制品校验与版本化契约提供。
- 两模块上线后，从 checkpoint 恢复其他开发。影响这两模块的公共底座问题继续修复。

暂缓知识检索、训练、模型评测审批及发布回滚、完整 Context Inspector、完整离线交付验收。保留现有实现与历史证据。

## 2. 色谱预测：五类专用表单

采用 `preview_coding_runtime.html` 的导航、输入区和结果区布局；字段以实际模型为准。当前“工具输入 JSON”和手填内部 ID 的交互改为正常业务表单，项目、结构引用、schema 版本及任务 ID 由系统管理。

| 类型 | 本轮必须完成的工具 | 实际输入条件 |
|---|---|---|
| TLC | 单次、批量、条件比较、反推溶剂 | 分子结构、模型支持的溶剂组成与比例；比较条件、反推目标 Rf 和候选范围 |
| CC | 单次、批量 | 分子结构、柱规格、洗脱体系、上样溶剂、样品质量、上样体积、流速 |
| HPLC | 单次、批量 | 两个对映体结构、候选手性柱、异丙醇比例、流速 |
| GC | 单次、批量 | 分子结构、线性温度程序或模型规定长度的温度序列 |
| SFC | 全柱、单柱、批量 | 双对映体、模型与分离阈值、Modifier 组成及总体比例、候选柱/固定相/模式/柱长/内径/粒径/温度/流速、Top-k；单柱增加柱组选择 |

具体要求：

- **SFC 对齐 v1.1 的实际字段和交互**，复用可用逻辑；不加入原型虚构的背压字段。候选值、单柱约束和模型列表来自服务端，比例归一化必须明确展示，计算规模按能力上限校验。
- TLC 继续复用 mo-group 曲线、拖动和反推交互；正式反推由后端计算，插值标为交互估计，不将石油醚替换为正己烷。
- 每类批量使用独立模板，支持上传、预览、逐行校验、确认提交、进度和失败行处理。
- 结果自动跟踪并展示实际模型版本、条件、数值、单位、警告和失败原因；支持历史记录回看、带回表单与已有受支持格式导出。
- CC 时间按既定公式由体积和流速派生；图表只展示实际能力支持的内容。
- 独立 `chiral_lc` 不计入本轮五类范围。

## 3. 智能助手与必要接口

助手默认进入业务模式，提供会话列表、聊天输入、工具进度、结果卡片、草稿卡片和确认操作。用户无需填写 Conversation、Run、Confirmation 等内部 ID。

首轮工具范围固定为：

- **预测工具**：能力查询、补问缺失条件、五类预测及对应批量/专属工具、查询结果；复用页面同一业务服务。
- **数据摘要**：当前项目已有数据版本和预测记录的数量、状态分布、缺失情况及适用数值统计，附来源和版本；统计由后端计算，助手负责解释。本轮不增加“上传任意文件做摘要”。
- **模型登记草稿/查询**：查询模型列表、模型卡和登记草稿；引用已校验制品创建、查看草稿。实际登记、评测、批准、发布和回滚不装配到本轮助手工具集中。

保留会话持久化、SSE 重连、刷新恢复、工具幂等和必要的确认流程。停止回答不自动取消已经提交的预测任务。

必要契约调整由总控审核：

- SFC 增加条件选项查询和候选范围创建接口，将专用条件表单解析为服务端校验、绑定项目及模型的不可变 `candidate_scope_id`；继续使用现有预测提交协议。
- 增加数据版本摘要和预测记录摘要的类型化查询接口，以及对应助手工具。
- SFC 结果补齐实际候选条件和模型输出含义，避免只返回不可读的候选 ID。
- 统一更新接口文档、OpenAPI、生成类型和契约测试，保留历史冻结快照。

## 5. 上线验收标准

- 五类预测及表中全部工具均可从浏览器录入、提交、等待并看到真实结果；每类批量均通过正常样例与部分失败样例。
- SFC 单柱/全柱在相同模型、结构和条件下与 v1.1 参考实现核对；其余类型与对应离线入口核对，记录数值容差。
- TLC 覆盖比例换算、拖动边界、插值标识、不可达目标和失败点；CC 验证单位；HPLC/SFC 验证双结构与立体信息。
- 助手能实际调用预测、解释真实摘要、创建并重新查询登记草稿；刷新后记录仍在，重复提交不重复产生业务副作用。
- 检查加载、空、成功、失败、窄屏、控制台、SSE 重连、Worker 重启恢复及取消竞态。
- 缺模型或 LLM 配置时保留明确阻塞，不能用 mock、失败页面或组件测试通过替代成功链路验收。
- 最终交付本机访问入口、启动/停止/重启说明、真实验收证据及延期功能 checkpoint 索引。
