## 状态定义与证据边界

- **限定 PASS**：仅在报告写明的日期、源码/运行窗口、输入和验收范围内通过；不自动扩展为完整功能、科学泛化、READY 或发布通过。
- **已实现未验收**：源码或候选存在，但没有对应真实业务链证据。
- **未运行**：相应业务路径没有真实执行。
- **阻塞**：记录明确的必需前置或失败门禁；未验证的资产数量、服务状态不得推测为阻塞或可用。
- **延期**：已从本阶段移出，有明确 checkpoint；不等于实现完成。

真实业务 PASS 至少要有当次日期与范围、运行身份/接口版本、浏览器或业务调用、持久化资源回查及结果/审计证据。静态检查、组件测试、fixture、候选包、Worker marker、健康接口或 `SUCCEEDED` 状态本身都不能证明业务完成。历史报告里的 PID、端口、容器健康和 READY 只属于该报告窗口；除非当次只读复核，不得描述为今天仍运行。
