# SFC 搜索表单

当前预测页 `PredictionView.vue` 使用 `SfcSearchForm.vue`，读取服务端返回的 SFC 1.1 工具、模型、健康状态、输入 schema 与候选轴选项。`SfcPredictionForm.vue` 是保留的历史组件，不代表当前页面。

表单绑定项目、工具和精确模型身份（model ID、版本及模型域）；选项与该绑定不一致或健康状态未就绪时，提交会关闭。八个候选轴及其值来自服务端选项，允许逐轴选择一个或多个值。单柱工具的 column 轴由模型组允许的具体色谱柱固定；全柱提交的轴选项不表示任意组合均有效，服务端按观察到的完整条件元组创建候选范围并返回实际候选数量。

预测需要当前项目内两个不同的规范化结构。Modifier 结构也在当前项目内规范化；组分比例可由用户显式选择归一化，总体积分数单独提交。`top_k` 和候选预算受已选工具的 schema 与 limits 约束。请求绑定精确模型选择，结果按服务端模型快照和实际返回的多行候选展示；结果标题使用返回结果中保存的模型阈值，概率表示 P(Rs ≥ 该阈值)；它是 Rs 分离度目标，不是概率筛选阈值，也不是候选条件轴。

全柱适用范围由服务端结果说明。轴值只来自模型适用域内观察到的条件；泛化能力及 Modifier 的科学适用范围尚未由模型元数据确立。代码实现了当前候选搜索流程，不表示部署中的模型已通过验证，也不表示全部 22 个模型或全柱科学能力已验收。页面只开放服务端报告为 `READY` 的能力。
